# أكاديمية مواهب الأحساء

مجلد المشروع الكامل للأكاديمية: الموقع، الهوية، والمستندات.

```
mawahib-academy/
├── brand/   الشعار الأصلي
├── docs/    البحث، خريطة الموقع، وقائمة المحتوى المطلوب من الأكاديمية
└── web/     الموقع (Next.js)
```

## الموقع

Next.js 16 + React 19 + Tailwind CSS 4 + TypeScript. عربي RTL بالكامل.

التشغيل محليًا:

```bash
cd web
npm install
npm run dev
```

ثم افتح http://localhost:3000

### النشر كموقع ثابت (GitHub Pages)

```bash
cd web
STATIC_EXPORT=1 BASE_PATH=/mawahib-academy npm run build
```

الناتج في `web/out`. النسخة الحالية لا تُفهرس في محركات البحث (`robots` في `layout.tsx` و`public/robots.txt`)، ويُزال ذلك عند الإطلاق الرسمي.

### أين أعدّل المحتوى

كل نصوص الموقع وبياناته في ملفين فقط، والواجهات تقرأ منهما:

- `web/src/content/site.ts`: الاسم، الجوال، واتساب، الحسابات، روابط القائمة.
- `web/src/content/academy.ts`: البرامج، المسار، المدربون، الخريجون، الأخبار، البطولات، الفعاليات، نجم الأسبوع، الآراء، الشركاء، الأسئلة، الجدول، الرسوم.

هذا الفصل مقصود: عند الانتقال للنظام تُستبدل هذه الملفات بجداول Supabase دون تغيير الواجهات.

### حدود هذه النسخة

- تسجيل الدخول ونماذج التسجيل والتواصل واجهات فقط، غير مربوطة بقاعدة بيانات.
- الصور مؤقتة من Unsplash (ترخيص مجاني)، معروضة بمعالجة لونية بهوية الأكاديمية لتُستبدل بصور الأكاديمية لاحقًا بنفس المعالجة.
- ما يحتاج تأكيدًا من الأكاديمية موجود في `docs/content-checklist.md`.
